# 策划文档索引

`planning/` 保存本项目本地输入材料的副本，供策划、前端、美术和测试共同查阅。

- `白蛇传_策划书_v2.docx`：玩法、内容目标与数据规范；
- `白蛇传_卡片编号.docx`：场景卡 S1–S6、角色卡 C1–C4 的编号依据；
- `白蛇传_故事组合附件.docx`：已验证的故事组合与生成文本；
- `孔雀东南飞_游戏内容策划书.pdf`：场景、角色、事件、规则、结局与五关设计。

代码引用卡片时只使用稳定 ID。中文名称、原始图片文件名与标准文件名之间的关系统一记录在 `card-id-reference.md`。

> 维护约定：若策划文档发生版本更新，请保留版本号或日期，避免直接覆盖仍在开发中引用的旧版本。
